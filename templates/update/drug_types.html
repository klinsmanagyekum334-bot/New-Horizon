How it works

  • Active types appear as filter chips on the homepage Pharma section.
  • Turning a chip off hides it from the site but keeps existing products tagged with that name.
  • Renaming a type automatically updates every product using the old name.
  • Deleting a type removes the chip, but products keep their current type label.
  • You can also just type a new type directly on the Add Product form — it gets registered here automatically.
